# Poké TCG

Monorepo for a single-player Pokémon TCG game: battle through the gym leaders of each Pokémon generation against CPU opponents. React SPA + Hono/tRPC API on Vercel, Supabase (Postgres, Auth), Prisma ORM.

**Current stage:** the game loop. The home screen is the current run (see [Runs](#runs)): encounters and battles chosen on a map, leading up to a gym leader, then the shop and the next run, played with a deck built on the Decks tab from your unlocked cards. The CPU's moves play out one at a time (see [The CPU opponent](#the-cpu-opponent)). Battles outside runs are on the Single battle tab (see [Single battles](#single-battles)). Multiple saves per account and later generations come later.

```
apps/
  web/                  Vite + React 19 SPA (TanStack Router/Query, tRPC client, Tailwind v4, Material UI icons)
    src/
      main.tsx          Routes, root layout (header with Play / Inventory / Packs / Cards / Decks tabs), providers
      pages/            Route-level pages: data loading only
      components/       Game UI components, one per file (run/: the run screens)
      hooks/            React hooks: interaction state and handlers used by components
      utils/            Pure helper functions grouped by use (no React)
      lib/              tRPC client, Supabase client, session hook
      styles/holo/      Holo card effect styles (one file per card style) plus WOTC tuning
    public/img/         Textures used by the holo styles
  api/                  Hono + tRPC API (Supabase JWT auth, card, deck, game and run endpoints, debug endpoints outside production)
    scripts/
      vercel-build.mjs  Bundles the API and web app into .vercel/output for Vercel
packages/
  game-engine/          Pure TS rules engine + CPU opponents – shared by client (UI hints) and server (authority)
  campaign/             Pure TS runs: map and encounters (reducer), deck lists and the deck generator, items, run types
  shared/               Zod schemas for API input, player ids, deck building rules (deck.ts)
  db/                   Prisma 7 schema, client (pg driver adapter), migrations, seed
supabase/               Local Supabase config (CLI)
CLAUDE.md               Project notes and decisions for Claude Code (read automatically each session)
```

## Web app structure

Pages load data, set their own width and side padding, and hand data to components. Components render. Hooks hold interaction state and behaviour. Utils are plain functions with no React, so the play rules for the UI can be read (and tested) on their own. Every move is still validated by the server.

### `src/styles/holo/`

Holo card effect: layered gradients, blend modes and textures moved by CSS variables that `HoloCard` sets from the pointer position. Each file styles one card type, selected by the card's `data-rarity`, `data-subtypes` and `data-supertype` attributes.

| File | Description |
|---|---|
| `index.css` | Imports everything in cascade order and sets the variables' resting values. Imported by `main.tsx` |
| `base.css` | Card structure (3D tilt, front/back, shine and glare layers) and the default glare every card gets |
| `cards.css` | Shared variables: textures, colours and art-window clip shapes measured on modern cards |
| `cards/*.css` | One style per rarity: `regular-holo.css` is the WOTC-era holo and `cosmos-holo.css` the galaxy foil; the others (reverse holo, V, VMAX, rainbow, secret, gallery…) are for later eras |
| `wotc.css` | WOTC tuning: card aspect ratio and art-window clip shapes re-measured on TCGdex scans for the classic (Base–Neo), Trainer and e-Card layouts, separate stage-badge shapes for Neo, and the galaxy-foil shape around the art; holo Energy is foil across the whole card; glare at half strength |

Holo cards are those with `variants.holo` in their TCGdex data (the rarity alone doesn't say: Base Set holos are listed as "Rare"). The API passes it on as `holo` in `cards.list` and in the engine's card definitions. Galaxy-foil cards (the Entei and Pichu promos and the Southern Islands set) have no TCGdex flag, so `isGalaxyFoil` in `apps/api/src/cards.ts` lists them. Base Set 2's 20 holo rares are shown with the galaxy foil too, to set them apart from the Base Set and Jungle holos they reprint; `cards.list` returns it as `galaxy`.

## Game engine (`packages/game-engine/src/`)

| File | Purpose |
| --- | --- |
| `engine.ts` | State types and the `applyAction` reducer: setup, playing cards, retreat, turn flow (Pokémon Checkup between turns, knockouts, prizes, promotions) |
| `attacks.ts` | Attack resolution: legality (`attackError`), the questions an attack asks (`nextAttackChoice`), weakness/resistance and prevention, and the context card effects run with |
| `powers.ts` | Pokémon Powers: legality (`powerError`), their questions (`nextPowerChoice`) and `usePower`; whether a power works (`powerActive`: Special Conditions and Toxic Gas), Prehistoric Power (`evolutionBlocked`), Clairvoyance (`seesOpponentHand`) and Ditto's Transform (`refreshTransforms`, run on every action) |
| `trainers.ts` | Trainer cards: legality (`trainerError`, including Headache's lock and Pokémon Tower), their questions (`nextTrainerChoice`), `playTrainer`, Stadiums (`stadiumError`, `pokemonTower`), and pending choices only the choosing player sees (`PendingChoice`, resolved with `RESOLVE_CHOICE`; attacks and powers start them too). A choice can belong to the player whose turn it isn't (Computer Error, Chain Reaction): the CPU answers its own first, and the game waits for the player's |
| `effects/` | Card-specific effects by card id: attacks (`base1.ts` for the Base Set, `jungle.ts` for Jungle, `fossil.ts` for Fossil, from shared pieces in `common.ts`), Pokémon Powers (`base1-powers.ts`, `jungle-powers.ts`, `fossil-powers.ts`) and Trainers (`base1-trainers.ts`, `jungle-trainers.ts`, `fossil-trainers.ts`, `neo1-trainers.ts`), and promo cards (`promos.ts` attacks, `promos-powers.ts`, `promos-trainers.ts`). Rules follow the 1999 Base Set rulebook. Turn order: `createGame` flips a coin for the first player (the human): heads they go first, tails the opponent does (`TURN_ORDER_FLIP`, logged with "Goes first."). Setup: each player puts a Basic Pokémon in the active spot and any Basic Pokémon cards on the Bench, hidden from the opponent (the log doesn't name them), can take them all back (`RESET_SETUP`), and presses Start battle (`START_BATTLE`, `PlayerState.ready`) when done; Clefairy Doll can't be placed then. Once both have started, the Pokémon are revealed in the log and whoever won the flip takes turn 1 (and can't attack on it); when that's the CPU, it plays its turn as soon as the player has started. The CPU places only its active and starts at once (it benches on its first turn). Special Conditions: Asleep (flip between turns to wake), Confused (flip to attack, tails = 20 damage to itself; flip to retreat), Paralyzed (until after its owner's next turn), Poisoned (10 between turns, 20 from Toxic), Burned (20 between turns, then a flip: heads cures it; no Base Set, Jungle or Fossil card Burns, but the promo Rapidash's Super Singe does). Poisoned and Burned are separate from each other and from Asleep, Confused and Paralyzed, which replace one another; only the active can have any of them, and benching, evolving and Full Heal remove them all. The checkup between turns handles them in order for both actives: Poisoned, Burned, Asleep, Paralyzed (tests in `burned.test.ts`). Trainers: PlusPower (+10) and Defender (−20) attach to a Pokémon and change attack damage after weakness and resistance, PlusPower first; they're discarded at the end of the turn / the opponent's next turn. Clefairy Doll is played onto the Bench as a 10 HP Pokémon (it can't start as your Active or count as a Basic for the opening hand), can't retreat or get Special Conditions, gives no prize when Knocked Out, and can be discarded during your turn. Scoop Up can't take your only Pokémon in play; Devolution Spray can Knock Out. Double Colorless Energy provides 2 Colorless energy. Pokémon Powers stop working while their Pokémon is Asleep, Confused or Paralyzed. Dropping a Water Energy on a Water Pokémon uses Rain Dance when a Blastoise can, so it doesn't use up the turn's attachment. Where TCGdex's attack text differs from the printed card, the effect carries the printed wording and the API shows that instead.

Team Rocket (`effects/rocket.ts`, tests in `rocket.test.ts`): every card is done: attacks, Pokémon Powers, Trainers and special Energy, and the set is in the run pool and has a pack. CPU decks (`generateDeck`) can use its Pokémon, but not its Trainers or special Energy, which the CPUs don't play. New mechanics: Stare switches off a Pokémon Power until the end of the opponent's next turn (`InPlayPokemon.powerOffUntil`, wherever it goes); Mirror Shell does the damage Dark Wartortle takes back to the attacker, with nothing applied to it; the opponent flips for Knock Down and Bench Manipulation (`ctx.oppFlip`); Fling and Vanish shuffle a Pokémon into its owner's deck (with nothing left in play after Vanish, its player loses); Energy Bomb puts each Energy card on a benched Pokémon the player clicks; Continuous Fireball's discards are the player's choice; Third Eye draws up to 3 (the player picks how many); Rapid Evolution evolves Magikarp from the deck with no evolution limits; Teleport Blast and Flame Pillar have "you may" choices (Don't switch; discard up to 1). TCGdex drops Energy symbols (Afternoon Nap, Fireball, Playing with Fire, Ember, Flame Pillar, Water Gun) and has Dark Magneton's attacks wrong on both prints; the effects carry the printed `text`, `damage` and `cost`. TCGdex also says the Dark Stage 2 Pokémon evolve from the plain Stage 1, so `apps/api/src/cards.ts` makes them evolve from the Dark one (Dark Alakazam from Dark Kadabra).

Team Rocket Pokémon Powers (`effects/rocket-powers.ts`): Summon Minions, Sneak Attack and Reel In work when their card is played from the hand, by evolving or with Pokémon Breeder (`onPlayFromHand`, called by `playedFromHand`): Summon Minions benches up to 2 Basic Pokémon from the deck (`pickFromDeck` with `count` and `optional`); Sneak Attack lets the player click one of the opponent's Pokémon on the board for 10 damage, with Weakness and Resistance, or skip it (the `oppPokemon` pending choice); Reel In takes up to 3 Pokémon cards from the discard pile (not with Pokémon Tower in play). Hay Fever stops both players playing Trainers (`trainersBlocked`). Sinkhole makes the opponent flip whenever their Active Pokémon retreats, 20 damage on tails. Sticky Goo adds 2 to the opposing Active Pokémon's retreat cost while Dark Muk is Active. Final Beam flips when an attack Knocks Out Dark Gyarados; heads does 20 per Water Energy on it to the attacker, with Weakness and Resistance. Frenzy works while Dark Primeape is Confused (`ignoresConditions`) and adds 30 to any damage it does, before Weakness and Resistance, so Confusion's self-damage is 50. Evolutionary Light, Pollen Stench, Matter Exchange, Gather Fire, Long Distance Hypnosis and Trickery are used once a turn; Trickery switches the Prize the player picks (face down, by position) with the top card of the deck. A power that takes a hand card but doesn't put it onto a Pokémon (Matter Exchange) is never used by dropping the card on a Pokémon.

Team Rocket Trainers and special Energy (`effects/rocket-trainers.ts`): Here Comes Team Rocket! turns both players' Prize cards face up for the rest of the game (`GameState.prizesFaceUp`; the view sends `prizes` for both sides). Rocket's Sneak Attack shows the opponent's whole hand in a dialog (the `oppHand` pending view) and the player clicks one of its Trainer cards for them to shuffle into their deck, or Done when there are none. The Boss's Way finds an Evolution card with Dark in its name. Challenge! asks the opponent (the `challenge` pending choice, answered with count 1 or 0); the CPU accepts whenever its Bench has room and its deck has a Basic Pokémon (agreed). Accepted, the player who played it benches any number of Basic Pokémon from the deck, then the opponent does (`challengeSearch`, `pickFromDeck` with `then`); declined, or with both Benches full, the player draws 2. Digger passes the flip back and forth until someone gets tails and takes 10 on their Active Pokémon. Imposter Oak's Revenge discards a card from the hand; the opponent shuffles their hand away and draws 4. Nightly Garbage Run shuffles up to 3 Pokémon or basic Energy cards from the discard pile into the deck. Goop Gas Attack stops every Pokémon Power on both sides until the end of the opponent's next turn (`PlayerState.powersOffUntil`, checked in `powerActive` and `powerError`). Sleep! puts the Defending Pokémon to sleep on heads. Rainbow Energy (`anyType` on the card, `'any'` in an `energyPool`) counts as every type while attached, one at a time: it pays any cost (`payCost`, which uses it for a typed symbol only when nothing else can), counts for effects about Energy of a type (Final Beam, Hydro Pump), and is a Fire (or any) Energy card for discards and moves (`isEnergyCardOf`: Ember, Fireball, Energy Trans, Gather Fire). Attached from the hand it does 10 damage to its Pokémon, which can Knock it Out. Full Heal Energy cures Asleep, Confused, Paralyzed and Poisoned, and Potion Energy removes a damage counter, when attached from the hand; both provide Colorless. Attaching Energy, and resolving a choice during the turn (Sneak Attack), now check for Knock Outs. The CPUs don't play these Trainers yet.

Base Set 2 (`effects/base4.ts`): every card reprints a Base Set or Jungle card (`BASE4_REPRINTS`; TCGdex words a few differently, but the printed cards play alike), so it takes the original's attacks, Pokémon Power or Trainer effect (`base4Reprints` in `effects/index.ts`), and every card is done. It's in the run card pool; a reprint is its own card there (unlocked separately from the original), and the 4-copy deck limit counts both, by name. `packages/campaign/src/base4.test.ts` checks the table against the TCGdex snapshot.

Jungle attacks: every Jungle Pokémon's attack effects are in `effects/jungle.ts`. Hurricane returns the Defending Pokémon and its cards to the hand unless it Knocks it Out. Chain Lightning does 10 to every benched Pokémon, on both sides, of the Defending Pokémon's type (none if it's Colorless). Teleport switches the attacker with a benched Pokémon the player clicks. Acid stops the Defending Pokémon retreating, Tail Wag and Leer stop it attacking that Pokémon, and Pounce and Snivel take 10 or 20 off its attacks on it, all during the next turn; benching or evolving either Pokémon ends them. Swords Dance makes Slash do 60 base damage on its owner's next turn. Big Eggsplosion flips a coin per Energy provided (Double Colorless = 2). Flareon's Flamethrower discards a Fire Energy card and Vaporeon's Water Gun counts Water Energy only (TCGdex drops those icons). Call for Family (Nidoran♀) finds either Nidoran; Call for Friend finds a Fighting Basic Pokémon.

Jungle Pokémon Powers (`effects/jungle-powers.ts`): Invisible Wall prevents attack damage of 30 or more to Mr. Mime, even from its owner's attacks, checked after weakness, resistance, PlusPower, Defender and other reductions. Thick Skinned stops Snorlax becoming Asleep, Confused, Paralyzed or Poisoned. Shift (once a turn) changes Venomoth's type to that of another Pokémon in play, not Colorless, until it leaves play or Shifts again. Heal (once a turn) flips a coin; on heads the player clicks one of their damaged Pokémon on the board to remove a damage counter (no choice if only one is damaged). Each working Retreat Aid on the Bench takes 1 off the Active Pokémon's retreat cost. Peek (once a turn) shows the player the top card of either deck, a random card from the opponent's hand, or a Prize card of either player they pick, until their next move; the log says only what they looked at.

Promos (`effects/promos.ts`, `promos-powers.ts`, `promos-trainers.ts`): every Wizards Black Star Promo (1–53) is implemented. Mewtwo (Wizards Promo 3 and 14)'s Energy Absorption attaches 1 or 2 Energy cards from the discard pile (it needs one there). Notes on the rest:
- **Baby Pokémon** (Cleffa, Pichu, Igglybuff; `baby` on the card, set by the API since TCGdex lists the promos as Basic): attacking an Active Baby takes a coin flip first, and tails ends the attacker's turn. A Baby evolves only into a card printed "Evolves from" it; none of the WOTC cards in the catalog are (TCGdex's "evolves from Pichu" on Basic Pikachu is Pokédex data, not printed). Pichu's Let's Play! puts a Baby from the deck onto the Bench.
- **Stadiums** (Lucky Stadium, Pokémon Tower): one is in play at a time for both players (`GameState.stadium`, shown in the turn bar). A new one sends the old one to its owner's discard pile, and one with the same name can't be played over it. Lucky Stadium: once during each player's turn, a flip; heads draws a card (`USE_STADIUM`). Pokémon Tower: Trainers that would put cards from a discard pile into the hand (Energy Retrieval, Item Finder, Super Energy Retrieval) can't be played, and attacks that would (Energy Conversion, Scavenge) leave the cards where they are.
- **Computer Error**: the player draws 0–5, then the opponent does (the CPU always takes 5; the player is asked during the CPU's turn), and the turn ends.
- **Rulings agreed**: it's never your birthday (\_\_\_\_\_\_\_\_\_\_\_'s Pikachu logs "It's not your birthday, liar"). Lightning Bolt does 20 instead of 10 to a Defending Pokémon with a Lightning Rod marker and 20 to each marked benched one, with Weakness and Resistance. Pure Body: the player picks which Energy card leaves Suicune, the new Water Energy included. Chain Reaction is offered to each Eevee's owner after any Pokémon evolves, either player's, under the usual evolution rules. Unown [J]'s Join works as printed, though Unown O, I and N aren't in the run card pool. Marill's Water Gun counts any Energy (its text names no type). On tails, Cat Punch's 20 damage goes to the benched Pokémon the opponent picks (the CPU picks the one with the most HP left).
- **New mechanics**: Light Screen (half damage, rounded down, after everything else), Togepi's Snivel (20 less before Weakness), Mini-Metronome (copies on heads, as Colorless, its discard still paid), Devolution Beam (either player's Evolved Pokémon), Neutral Shield (attacks by Evolved Pokémon), Protective Flame and Aurora Veil (attacks can't affect the Bench), Guard (the Defending Pokémon can't retreat), Bolt (shuffled away after the attack), Paint (a Coloring counter changes the type until it leaves play), Lightning Rod markers (stay until it leaves play). Aurora Veil and Guard also stop while Poisoned or Burned.
- TCGdex leaves out the printed damage of Poison Claws (10) and Sacred Fire (60) and drops Energy icons from Recharge, Flames of Rage, Hyper Flame, Burning Fire and Mini-Metronome; the effects carry the printed values (`damage`, `text`).

Jigglypuff (Wizards Promo 7) has First Aid and Double-Edge. Electrode (Pokémon Web 26) is a Japanese-only card added by hand (`custom-cards.json`): Sonicboom ignores weakness and resistance, and Energy Spike finds a basic Energy card in the deck, then the player clicks the Pokémon to attach it to; the turn ends after both steps. Super Energy Retrieval (`effects/neo1-trainers.ts`, the Neo Genesis printing, standing in for the deck's Japanese Fan Book promo) trades 2 other cards from the hand for 4 basic Energy cards from the discard pile, or all of them if there are fewer.

Jungle Trainers (`effects/jungle-trainers.ts`): Poké Ball needs a card in the deck; on heads the player takes a Basic Pokémon or Evolution card from the deck (they must when there is one), and the log names the card taken, as it's shown to the opponent.

Fossil attacks: every Fossil Pokémon's attack effects are in `effects/fossil.ts`. Damage to benched Pokémon (Dark Mind, Stretch Kick, Gigashock, Thunderstorm, Blizzard, Selfdestruct, Earthquake) ignores weakness and resistance, but Defender still takes 20 off it, as it does off damage an attack does to the attacker itself (Selfdestruct, Thunder, Double-edge…, and the 20 a Confused Pokémon does to itself on tails). Headache works even if the Defending Pokémon is protected by Agility or Barrier. Energy Conversion needs an Energy card in the discard pile and takes 1 or 2 of them. TCGdex drops the energy icons from card text ("each Energy" for "each Water Energy"), so effects carry the printed wording: Fossil's Water Guns count extra Water Energy only, and Scavenge discards a Psychic Energy card. Minimize takes 20 off attack damage after weakness, resistance, PlusPower and Defender. Smokescreen works like Sand-attack. Headache stops the opponent playing Trainer cards, Clefairy Doll included, during their next turn; it's on the player, so switching doesn't end it. Prophecy (either deck) and Call for Family leave a search to finish, and the turn ends once it's done. Terror Strike, like Whirlwind and Ram, has the opponent choose which benched Pokémon comes in.

Fossil Pokémon Powers (`effects/fossil-powers.ts`): Toxic Gas makes every other power stop working, on both sides, while Muk isn't Asleep, Confused or Paralyzed. Prehistoric Power stops both players playing Evolution cards (Pokémon Breeder included). Ditto's Transform, while it's the active and has no Special Condition, makes it a copy of the Defending Pokémon: type, HP, Weakness, Resistance, retreat cost, attacks and power; its Energy counts as any type; damage stays, so it's Knocked Out if it stops being a copy with more damage than its own 50 HP. Step In and Curse can be used once per turn per Pokémon; Curse can Knock Out, and the opponent then promotes without the turn ending. Strange Behavior can't Knock Out Slowbro. Transparency flips once per attack against any attack that does anything to Haunter, even its owner's, and only Sleep stops it. Kabuto Armor halves attack damage, rounded down to the nearest 10, after weakness, resistance, PlusPower and Defender. Clairvoyance shows the opponent's hand in the player's view. Cowardice returns Tentacool to the hand (not the turn it was put into play, nor your only Pokémon), discarding its cards.

Fossil Trainers (`effects/fossil-trainers.ts`): Mr. Fuji shuffles a benched Pokémon and everything attached into the deck. Energy Search takes a basic Energy card from the deck. Gambler shuffles the hand into the deck, then draws 8 on heads or 1 on tails. Recycle needs a card in the discard pile; on heads the player picks one (not Recycle itself) to put on top of the deck. Mysterious Fossil follows Clefairy Doll's rules (a 10 HP Pokémon on the Bench, never the starting Active, no prize when Knocked Out, can be discarded during your turn). Omanyte, Kabuto and Aerodactyl evolve from it, and Pokémon Breeder can put Omastar or Kabutops straight onto it. TCGdex leaves out "evolves from Mysterious Fossil", so `apps/api/src/cards.ts` fills it in.

## Runs

An account plays runs, one at a time. A run is steps of encounters, choosing one of 2–3 at each step (you can see what later steps offer), with bosses along the way: every gym leader comes after one of their gym's trainers, who must be fought, and the run is beaten with its last boss. The pure logic is in `packages/campaign` (`RunState` and its reducer `applyRunAction`, like the engine's), the API saves it in the `Run` table, and the web shows it on the home screen.

**Run types** (`run-types.ts`):

| Run | Steps | Bosses |
| --- | --- | --- |
| Pewter, Cerulean, Vermilion, Celadon, Fuchsia, Saffron, Cinnabar and Viridian City | 24 encounters, the Gym Trainer, the gym leader (26 in all) | Brock, Misty, Lt. Surge, Erika, Koga, Sabrina, Blaine or Giovanni |
| Kanto Gym Challenge | For each gym in order: 5 encounters, the Gym Trainer, the gym leader (56) | All eight gym leaders |
| Kanto Champion | For each gym: 4 encounters, the Gym Trainer, the gym leader; then Victory Road (5 encounters) and the Elite Four and Champion back to back (58) | All eight, Lorelei, Bruno, Agatha, Lance and Champion Blue |

**Bosses** (`bosses.ts`) play their counterpart's deck from the Game Boy Color *Pokémon Trading Card Game* (TCG 1), named for the Generation I character: Brock (Gene's Rock Crusher), Misty (Amy's Rain Dancer), Lt. Surge (Isaac's Zapping Selfdestruct), Erika (Nikki's Flower Power), Koga (Rick's Wonders of Science), Sabrina (Murray's Strange Psyshock), Blaine (Ken's Fire Charge), Giovanni (Mitch's First-Strike); the Grand Masters' Legendary decks for the Elite Four, Lorelei (Jack's Articuno, Ice), Lance (Rod's Dragonite, Dragon), and by elimination Bruno (Steve's Zapdos) and Agatha (Courtney's Moltres); and Ronald's Legendary Ronald Deck for Champion Blue. Cards that only exist in the Game Boy game (its promos, its "Mystery" and "Laboratory" prints and the Japanese Fan Book card) are replaced by the closest TCGdex card of the same type, noted on each deck (e.g. Fossil Moltres for the promo Moltres, Fossil Dragonite for the promo Dragonite, Jungle's Eeveelutions, Neo Genesis Super Energy Retrieval). The Japanese-only Pokémon Web Electrode (Lt. Surge, Bruno) is in the catalog, added by hand, so it plays as itself. Ronald's promo Articuno and Zapdos are Moltres instead, as no Water or Lightning Pokémon can attack with his Fire and Double Colorless Energy. Bulbapedia's First-Strike and Rain Dancer lists add up to 61, so each has one basic Energy fewer. Bosses play at Gym leader difficulty; a loss costs 1 HP and they're fought again. Beating one gives more ₱ and EXP, a choice of rarer cards, and their badge (or, for Blue, the Champion Ribbon) as a key item at once.

- **Start**: the first visit sets up the account: a `Starter deck` (`STARTER_DECK`, medium strength, Water/Lightning: Poliwag and Pikachu lines, Lapras, Electabuzz, 17 Trainers, 24 Energy) saved in its deck list with every card in it unlocked, and a first run of **Celadon City** with it. A run starts with 3 HP and ₱500. Older accounts get their starter deck's cards unlocked on their next visit.
- **Battles**: the trainer plays a random 60-card deck of medium strength (`generateDeck`: 1–2 types, 2–4 middling evolution lines, 14–16 Trainers, all ones a CPU plays, the rest Energy split by the attacks' needs; the same seed gives the same deck) at the CPU's **Trainer** difficulty. Its deck suits the trainer's name: each class (Swimmer, Bug Catcher, Hiker, Bird Keeper…) favours Generation I Pokémon (`trainerFavorites`), whose lines are chosen first and set the deck's types, so a Swimmer plays Tentacruel, Golduck or Starmie rather than any Water Pokémon; other lines join only when the favourites run out. A **Gym Trainer** is the only option on the step before their gym leader: a random deck of the gym's type alone, at Trainer difficulty. **Ace Trainers** (elite battles, from step 6) can be declined; they play at **Gym leader** difficulty and pay more. A win pays ₱ and EXP and offers 1 of 3 cards; a loss costs 1 HP and the run moves on, except against a boss, who is fought again. At 0 HP the run is lost: start over (a new run), or, for testing, **Retry with 3 HP**, which carries on from where it ended (on in production too, for now).
- **Other encounters**: a card shop (cards for ₱ by rarity), a free card (1 of 3), a card trade (one of your deck's cards for one at least as rare; it replaces it in the deck), a Pokémon Center (1 HP for ₱100) and Mystery events: a Frenzy (Pokémon of one type do double damage in the next 3 battles, both sides: the engine's `GameState.rules`), a coin-toss bet, a shady dealer (a rare card for 1 HP), a Fan Club donation (₱ for EXP) and a lucky find.
- **Cards**: cards come from every card the engine plays fully (`cardImplemented`) in the Base Set, Jungle, Fossil, Wizards promos, Base Set 2 and Team Rocket (`apps/api/src/pool.ts`), rarer ones less often. A card gained in a run is unlocked at once (`CardUnlock`, `apps/api/src/unlocks.ts`) but doesn't join the run's deck (only trades change it): it can go in your next decks on the Decks tab. Unlocks are per card, not per copy (up to the usual 4); basic Energy is always unlocked. Base Set 2's commons reprint earlier commons with the same art, so unlocking either one unlocks the other too, whether it's the original or its Base Set 2 common (`unlockCards`; the migrations `20261018090000_base2_common_unlocks` and `20261018100000_base2_common_originals` did this for unlocks made before). Only Base Set 2, and only its commons. The Decks tab shows locked cards darker (and still, without the holo effect, when viewed large), the deck builder won't add them (nor will the API save them), and a deck holding any can't start a run or a single battle.
- **After a run**: beating it adds its EXP to the account and gives the gym leader's badge (a key item). Then comes the shop, where items cost EXP, and then the next run, with a run type and one of your playable decks to pick. When a run ends, beaten or lost, its leftover ₱ go into the account's bank (`User.bank`) at once; the next run starts with ₱500. (Retry with 3 HP takes them back out of the bank, as far as it still has them.)
- **Conceding**: while choosing the next step, Concede the run (`ConcedeRun`, the `CONCEDE` run action) ends it as lost (`RunState.conceded`) after asking. The cards gained stay unlocked (they were unlocked as they were gained). Its ₱ are banked only if at least one battle was finished, won or lost (`battlesFought`, `bankablePokedollars`: older runs count their battles from the log), so a fresh run's ₱500 can't just be banked. There's no EXP (that's for beating a run) and no retry.
- **Items** (`items.ts`; prices and strengths are first guesses, to balance later). Owned items are `InventoryItem` rows.
  - **Equipment** goes in head, chest, legs, Poké Ball and 2 accessory slots (`Equipment`). It's read when each run action is applied, so a change works from the next encounter. Head: ₱ per win, more EXP, more reward cards. Chest: less damage to your Pokémon (of one type, or all). Legs: cheaper Pokémon Centers or Card Shops, more Free Card choices. Poké Balls: more cards in the opening hand, and more cards to pick from. Accessories: +10 damage for one type's attacks (Charcoal, Mystic Water…), more ₱ or EXP, a lucky first coin flip (Coin Case).
  - **Consumables** are used from the Bag before a battle (at most 3 per run) and last a number of battles: X Attack and Dire Hit (more damage), X Defend (less damage taken), X Accuracy (first flips heads), Guard Spec., Antidote, Awakening, Paralyze Heal, Burn Heal and Full Heal (no Special Conditions from attacks), Lemonade (bigger opening hand), Lucky Egg (double EXP), Big Pearl (more ₱).
  - **Misc items** do one thing when used, with their own limits: Escape Rope (leave a battle without losing HP; its game is conceded, and a boss or Gym Trainer stays to be fought again), Itemfinder (reveal the step's Mystery encounters), Repel (re-roll the step's encounters, not at a gym), Potion (heal 1 HP), Nugget (₱300).
  - **In battles**, equipment and consumable effects become the player's battle rules (`damageBonus`, `damageGuard`, `conditionGuard`, `openingHand`, `luckyFlips`; see `BattleRule`), each named for its item. Damage bonuses add to the base damage (after a Frenzy's multiplier, before Weakness); guards come off after Weakness and Resistance, like Defender. In the run, they change battle prizes and EXP, prices, and how many cards are offered.
  - **Key items** are records that can't be removed.
- **API** (`routers/run.ts`, `runs.ts`, `pool.ts`, `unlocks.ts`): `run.overview` (with each deck's problems), `act` (with `expectedVersion`, like games), `useItem`, `retry`, `start` (a playable deck), `shop`, `buyItem`, `inventory`, `equip`; `decks.unlocked`. Starting a battle creates a `Game` linked to the run (`Game.runId`); when the game ends, `game.act` (or the next `run.overview`) records the result in the run.

## Booster packs

The ₱ in the bank (each run's leftover ₱, moved there when the run ends) buys booster packs on the **Packs** tab, ₱300 each (`PACK_PRICE`). There's one per set whose card effects are done (`PACK_SETS`: Base Set, Jungle, Fossil, Wizards Black Star Promos, Base Set 2, Team Rocket). A pack is 11 cards with the usual WOTC-era make-up, averaged rather than each set's own odds: 1 rare, a holo about 1 pack in 3 (`HOLO_CHANCE`), 3 uncommons and 6 commons, all different, and 1 basic Energy of any type (Jungle and Fossil have none of their own). TCGdex lists every promo as Common (6 of them holo), so a promo pack's uncommon and rare slots hold more non-holo promos, and its last card is a holo promo about 1 pack in 3; the pack window labels them "Promo" and "Holo Promo". `openPack` in `packages/campaign/src/packs.ts` rolls it; the API's `packs` router (`apps/api/src/routers/packs.ts`: `list`, `open`) takes the ₱ from the bank, rolls the packs on the server and unlocks every card in them, in one transaction, and returns the cards in reveal order (each pack's Energy first and rare last, pack after pack, each with its `pack` number) with which are new unlocks (only the first time a card comes up). Up to `MAX_PACKS_AT_ONCE` (50) packs can be bought at once (`count`). The page shows the sets as packs, each with how many of the cards its packs can hold you've unlocked (`unlockedCount` of `packCards` from `packs.list`, basic Energy aside) and a progress bar; clicking one opens a window with that pack and a quantity picker (×1, ×2, ×5, ×10, or Custom with a Max button for what the bank pays for), and two options remembered in the browser: separate commons and rares (the commons, uncommons and Energy of all the packs are laid out face up together, and the rares stay face down to be opened one by one) and auto open (each card moves on by itself, pausing longer on rares and holos; while it runs, ×2 speed doubles it, and Stop auto goes back to clicking for the rest of the packs, with Resume auto to start it again). Clicking the pack opens them with an animation, then the cards one at a time or all at once (Skip), and finally the list of cards opened.

## Single battles

The **Single battle** tab (`pages/SingleBattle.tsx`) plays one battle outside runs: nothing is won or lost. Pick:
- **Your deck:** one of your decks that can be played (the others are listed with why not), or the fixed Base Set test deck (`PLAYER_TEST_DECK` in `apps/api/src/test-decks.ts`). The deck for the next battle is shown large at the top, with its headline Pokémon and card split, and links to the Decks tab to edit it (`/decks?deck=<id>`) or build a new one (`/decks?deck=new`).
- **Opponent:** a random trainer from the run's map (`TRAINERS`), with a new random deck suiting their name each battle (`generateDeck` with `trainerFavorites`, as in runs), or a boss (any gym leader, the Elite Four or Champion Blue) with their own deck.
- **Difficulty:** Passive, Trainer (the default) or Gym leader, whatever the opponent.

The choices are remembered in the browser (`poke-tcg.single-battle`), so after a battle the Next battle button goes back to the tab with them still picked. `game.create` (`singleBattleInput` in `@poke-tcg/shared`) starts it; the opponent's name is kept in the game's state (`opponentName`) for the banner at the top of the game.

## How a move works

1. Client sends `game.act({ gameId, expectedVersion, action })`.
2. API validates the input with Zod, loads the game state, and runs `applyAction` from `@poke-tcg/game-engine`.
3. If the move is legal, the API runs the CPU (`runCpu`) until it's the player's move again.
4. If `expectedVersion` still matches, the API writes the new state and every action (player and CPU) to the `GameAction` log in one transaction.
5. The response is `frames`: the player's `getPlayerView` after their move and after each of the CPU's, with who moved and the action type. Raw state, which includes the CPU's hand, deck order and RNG, never leaves the server.
6. The web caches the last frame and plays the others back (`pages/Game.tsx`): each move's coin flips play first (1.9s each) while the board still shows the move before, so no result shows before its coin lands; then the move stays up for 0.9s. A click skips a move's flips, and with "Always skip coin flips" (saved per browser) they don't play at all. Nothing can be clicked until the reply ends, coin flips included. Slots animate what changed (`Slot.tsx`): a Pokémon dropping in, a red shake for damage, green for healing, yellow for Energy, and the attacker lunging at the defender.

## The CPU opponent

Each difficulty has its own file in `packages/game-engine/src/cpu/`, with shared helpers in `shared.ts`. A game's `cpuDifficulty` picks one (missing = Gym leader), and the Debug tab can change it mid-game:

- **Passive** (`passive.ts`): benches Basics, evolves and attaches Energy to a Pokémon of the same type. It never attacks, retreats or plays Trainers.
- **Trainer** (`trainer.ts`), for the fights that aren't gym leaders: plays Bill and Professor Oak (same rules as the gym leader), benches and evolves, aims its Energy attachment like the gym leader, heals only its active (Potion at 20+, Super Potion at 40+ if it can still use its best attack), retreats or switches only when the active can't attack this turn or next and a benched Pokémon can, and attacks for the most damage even when that costs Energy or hurts itself. It never uses Pokémon Powers, searches its deck, disrupts, boosts, or looks at the player's next turn. After a Knock Out it promotes the Pokémon with the most HP left.
- **Gym leader** (`gym-leader.ts`): the strongest, described below.

The gym leader takes, on its turn, it takes the first move any of these steps wants, over and over, until it attacks or ends its turn:

1. **Draw and search**: Bill (keeping cards to draw). Computer Search for the next stage of a line in play, or a Basic if the Bench is empty, discarding Energy nothing can use, spare Trainers, Trainers it never plays and Pokémon it can't use (never anything else). Pokémon Trader swaps a Pokémon it can't use for one it wants. It only searches when the card could still be in its deck (counting the face-down prizes). Pokédex isn't played.
2. **Develop**: bench Basics, Pokémon Breeder straight to Stage 2, evolve (active first), and a Clefairy Doll only when the Bench is empty.
3. **Energy**: Rain Dance and the turn's attachment go to the active if they make a new attack usable, otherwise to the benched Pokémon they bring closest to attacking; Double Colorless only where two colorless symbols are open, and never Energy no attack can use. Energy Trans moves Grass Energy from the Bench to the active when that makes a stronger attack usable. Then Professor Oak, if the hand is down to 2 other cards (and the deck has more than 7).
4. **Heal**: Full Heal for a Special Condition; Super Potion on the active at 40+ damage if it can spare the Energy and still use its best attack, else the most damaged benched Pokémon at 40+; Potion at 20+ damage (active first); Pokémon Center for 60+ healed when the active isn't about to attack with Energy it would lose; Damage Swap moves damage counters off an active that would be Knocked Out.
5. **Disrupt**: Energy Removal on the player's active (else the Pokémon closest to its strongest attack); Super Energy Removal only when both Energy were going towards one attack, discarding its own Energy that's missed least; Gust of Wind for a Knock Out, else to strand a benched Pokémon with no Energy and a Retreat Cost of 2+.
6. **Retreat or Switch** (Switch first): when the active can't attack this turn or next but a benched Pokémon can; when it would be Knocked Out next turn (and isn't Knocking Out the attacker first) and a benched Pokémon would survive; or when it still has a Special Condition. The benched Pokémon that attacks best comes in. The Retreat Cost is paid with the Energy it can best spare, basic before special, and never when nothing could attack afterwards.
7. **Boost**: any Pokémon Power that makes this turn's attack better without costing a Pokémon or prize (Energy Burn); PlusPower when +10 makes a Knock Out; Defender when −20 stops a Knock Out next turn.
8. **Attack**: the cheapest attack that Knocks Out, otherwise the most damage. Attacks that hurt the attacker or discard its Energy only when they Knock Out or nothing else does damage.

After a Knock Out it promotes the benched Pokémon that attacks best (then the one with the most HP left). It plays no other Trainers yet (Lass, Impostor Professor Oak, Item Finder, Maintenance, Revive, Pokémon Flute, Scoop Up, Devolution Spray, Energy Retrieval, and the promos' Computer Error, Lucky Stadium and Pokémon Tower), never uses Buzzap, Lucky Stadium or the promo powers it doesn't recognise, and only answers the choices other cards ask of it: every difficulty draws 5 for Computer Error, takes an Eevee evolution for Chain Reaction, puts back the card it wants least for Special Delivery, and keeps the Energy that leaves Suicune closest to attacking for Pure Body.

It only uses what the player could see. What an attack would do is worked out in `cpu/shared.ts` by playing it on copies of the state with fixed coin flips covering every heads/tails pattern of three flips, so it never knows the real flips to come; "Knocks Out" means in at least half of those outcomes. The player's threat is their active's best attack next turn with the Energy it has now. Trainers and powers are recognised by name, so reprints work the same, and nothing depends on the current test decks.

## Deck builder

The **Decks** tab (`pages/Decks.tsx`) builds decks for runs and single battles. It opens on the deck list: a button per deck showing its name, card count, its 3 headline Pokémon and how its cards split between Pokémon, Trainers and Energy. The headline Pokémon are the highest stages, preferring an evolved Pokémon with 2 or more copies of each earlier stage in the deck, then the most copies, one per evolution line while there are enough lines. From the list you can start a new deck, rename one with the pencil button by its name (Enter or clicking away saves the name, Escape cancels), copy one (the copy, "<name> (copy)", goes at the end and opens for editing), or drag decks into a new order (`Deck.position`, which Play's deck pickers follow too). Click a deck to open it: it stays at the top as a button back to the list, where its pencil button renames it (saved with the deck's Save, like its cards), with Save and Delete and its cards below, where − and + change the counts; click cards in the search to add copies. Right-click any card (in the search, the open deck, or a deck's headline Pokémon) to see it large, as holding it does; it stays open until Escape or a click outside, and with a deck open it has − and + to change the card's copies in it. Decks are saved per user (`Deck`, `DeckCard`) through the `decks` router (`apps/api/src/routers/decks.ts`: `list`, `get`, `save`, `rename`, `duplicate`, `reorder`, `delete`).

The rules (`packages/shared/src/deck.ts`, used by both the builder and the API) are the rulebook's: exactly 60 cards; at most 4 cards with exactly the same name, across all sets, except basic Energy (TCGdex "Normal" Energy; Double Colorless, Darkness and Metal Energy are special); and at least one Basic Pokémon (Baby Pokémon count; Clefairy Doll and Mysterious Fossil don't). An unfinished deck can be saved, but never one over 60 cards or with more than 4 of a name, and only a deck with no problems can start a run (`run.start`) or a single battle (`game.create`).

Only unlocked cards can go in a deck (see [Runs](#runs)): the starter deck's cards, every card gained in a run, and basic Energy, which always is. Locked cards are darker on the Decks tab, and shown still, without the holo effect, when held or right-clicked. The API won't save a deck with a locked card, and a deck that holds one (saved before unlocks) lists it as a problem.

Every catalog card can go in a deck. `cards.list` marks the ones the engine fully implements (`isImplemented` in `apps/api/src/cards.ts`: every attack with text, its power, its Trainer effect, or basic, Double Colorless, Rainbow, Full Heal and Potion Energy), for the "Implemented only" filter and the deck list's "(partial)". The rest still load: their Pokémon attack for base damage, while their other attack effects, powers, Trainer effects (the card can't be played) and special Energy effects (1 Energy of its type, or Colorless) do nothing yet.

The kind toggles (Pokémon, Trainer, Energy) show any of the kinds that are on; with none on, every kind shows, so Trainer and Energy together show every Trainer and Energy card. The type toggles pick types for Pokémon (their type) and Energy (the type it provides; special Energy without one of its own, like Double Colorless, is Colorless) alike. The type toggles and the Pokémon filters (stage, HP, has ability) only say something about the cards they apply to: the cards they don't apply to (Trainers for the types; Trainers and Energy for the Pokémon filters) still show when their kind is on, and are hidden otherwise. So Fire alone shows Fire Pokémon and Fire Energy, and Fire with Pokémon and Trainer on shows Fire Pokémon and every Trainer (`filterForDeck`).

## Debug tools

The game log has a **Debug** tab for testing: change the CPU's difficulty, draw a card, put any card (or an Energy) into your hand, set the HP of any Pokémon in play, and turn Special Conditions (Asleep, Confused, Paralyzed, Poisoned, Burned) on or off on either active, for example to try Burned before any card inflicts it. It only exists outside production, enforced in two places:

- **API** (the authority): the `debug.run` procedure is a `debugProcedure` (`apps/api/src/trpc.ts`), which answers `NOT_FOUND` unless `env.debugEnabled` (`apps/api/src/env.ts`). That's always false in production (`VERCEL_ENV=production` or `NODE_ENV=production`, whatever else is set), and true elsewhere unless `ENABLE_DEBUG=false`. `debug.enabled` tells the client which.
- **Web**: `__DEBUG_BUILD__` is a build-time constant from `vite.config.ts`: on in the dev server (unless `VITE_ENABLE_DEBUG=false`), off in a `vite build` (unless `VITE_ENABLE_DEBUG=true`). A production build leaves the Debug tab's code out of the bundle entirely; the tab also needs `debug.enabled` from the API.

Debug commands go through the engine's `applyDebug` (`packages/game-engine/src/debug.ts`), are written to the game log as "Debug: …", and are saved in the `GameAction` log as `{ type: 'DEBUG', command }`.

## Setup

Requires Node 24+, pnpm, and Docker if you want local Supabase.

```sh
pnpm install
cp .env.example .env        # fill in values (see below)
pnpm db:migrate             # create tables (prompts for a migration name)
pnpm db:seed                # load the WOTC card catalog (1999–2003) from the TCGdex snapshot, plus the hand-made cards
pnpm dev                    # web on :5173 and API on :8787, both with live reload
```

### Option A – hosted Supabase project

1. Copy the pooled (6543) and direct (5432) connection strings into `DATABASE_URL` and `DIRECT_URL`. They're under **Project Settings → Database**.
2. Copy the project URL and anon key into `SUPABASE_URL`, `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
3. Enable the Google provider under **Authentication → Providers**.
4. Under **Authentication → URL Configuration**, add `http://localhost:5173` and your Vercel URL to the redirect URLs.

### Option B – local Supabase (Docker)

```sh
pnpm supabase:start         # prints the local URLs and keys
```

Use the printed DB URL for both `DATABASE_URL` and `DIRECT_URL`, `http://127.0.0.1:54321` as the Supabase URL, and the printed anon key. If the local project signs tokens with HS256, also set `SUPABASE_JWT_SECRET`.

### Google OAuth

1. In Google Cloud Console, create an OAuth client ID of type *Web application*.
2. Add this authorized redirect URI: `https://<project-ref>.supabase.co/auth/v1/callback`. For local Supabase use `http://127.0.0.1:54321/auth/v1/callback`.
3. Paste the client ID and secret into the Supabase dashboard. For local Supabase, set `SUPABASE_AUTH_EXTERNAL_GOOGLE_CLIENT_ID` and `SUPABASE_AUTH_EXTERNAL_GOOGLE_SECRET` in `.env`.

## Deploying to Vercel

1. Import the repo into Vercel and leave the **Root Directory** as the repo root. `vercel.json` sets the build command, which writes `.vercel/output` (Build Output API): the web app as static files and the API bundled into one function serving `/api/*`.
2. Add the variables from `.env.example` in the Vercel project settings. Use the **pooled** `DATABASE_URL`.
3. Run migrations against production from your machine or CI with `pnpm --filter @poke-tcg/db migrate:deploy`. They don't run during the Vercel build, so preview deploys can't touch the production schema.
