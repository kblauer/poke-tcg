# Poké TCG

Monorepo for a single-player Pokémon TCG game: battle through the gym leaders of each Pokémon generation against CPU opponents. React SPA + Hono/tRPC API on Vercel, Supabase (Postgres, Auth), Prisma ORM.

**Current stage:** the game loop. The home screen is the current run (see [Runs](#runs)): encounters and battles chosen on a map, leading up to a gym leader, then the shop and the next run, played with a deck built on the Collection tab from your unlocked cards. The CPU's moves play out one at a time (see [The CPU opponent](#the-cpu-opponent)). Battles outside runs are on the Single battle tab (see [Single battles](#single-battles)). Multiple saves per account and later generations come later.

## Web app structure

Pages load data, set their own width and side padding, and hand data to components. Components render. Hooks hold interaction state and behaviour. Utils are plain functions with no React, so the play rules for the UI can be read (and tested) on their own. Every move is still validated by the server.

Rules follow the 1999 Base Set rulebook. Turn order: `createGame` flips a coin for the first player (the human): heads they go first, tails the opponent does (`TURN_ORDER_FLIP`, logged with "Goes first."). Setup: each player puts a Basic Pokémon in the active spot and any Basic Pokémon cards on the Bench, hidden from the opponent (the log doesn't name them), can take them all back (`RESET_SETUP`), and presses Start battle (`START_BATTLE`, `PlayerState.ready`) when done; Clefairy Doll can't be placed then. Once both have started, the Pokémon are revealed in the log and whoever won the flip takes turn 1 (and can't attack on it); when that's the CPU, it plays its turn as soon as the player has started. The CPU places only its active and starts at once (it benches on its first turn). ## Runs

An account plays runs, one at a time. A run is steps of encounters, choosing one of 1–3 at each step (you can see what later steps offer), with bosses along the way: every gym leader comes after one of their gym's trainers, who must be fought (except in the Gym Challenge and Champion runs), and the run is beaten with its last boss. Step rules (agreed): at least 4 steps are a required battle, which can't be skipped (`REQUIRED_BATTLES`; the first step always is one, the others are random); a run offers at most 2 Pokémon Centers (`MAX_CENTERS`); the other steps offer 1, 2 or 3 options (weights 4:2:1, `OPTION_COUNTS`), so a step offering a non-battle encounter has only that one about half the time (a lone shop or gift is simply where the road goes). A step offering a single trainer and nothing else (required or rolled) offers a second trainer to choose between 75% of the time (`PAIR_CHANCE`, agreed; steps with a non-battle option keep their options), so about two thirds of the steps offering a trainer battle offer two in a 10-encounter run; one of them must still be fought. The pure logic is in `packages/campaign` (`RunState` and its reducer `applyRunAction`, like the engine's), the API saves it in the `Run` table, and the web shows it on the home screen.

**Generations** (agreed): runs belong to a generation (`GENERATIONS` in `run-types.ts`): Gen 1 is Kanto, Gen 2 Johto. Each has its own sets (`poolSets`): Gen 1's are Base Set to Gym Challenge and Legendary Collection (its Gen 1 reprints, agreed), Gen 2's Neo Genesis, Neo Discovery, Southern Islands, Neo Revelation, Neo Destiny, Expedition, Aquapolis and Skyridge (`GEN2_SETS`). A run's cards (gifts, rewards, shops, trades, events) and its trainers' random decks come only from its generation's sets (`cardPool(gen)`/`runPool` in `apps/api/src/pool.ts`), and the random decks use the generation's basic Energy and Trainers (`DeckRules`: `GEN1_DECK_RULES`, `GEN2_DECK_RULES` in `decks.ts`; Gen 2 has no Double Colorless or Pokémon Breeder). Gen 2 is partly scaffolding: every Gen 2 set's card effects are done (`GEN2_DONE_SETS`: Neo Genesis to Skyridge). A generation's pool takes only the cards the engine plays fully from its finished sets (`implementedSets`: all of Gen 1's and Gen 2's), and every card of the others, implemented or not: their Pokémon attack for base damage, and their Trainers can't be played yet. The CPUs don't play Gen 2's Trainers yet. The trainer classes' favourite Pokémon (`trainerFavorites`) list Johto Pokémon after Kanto's, so Gen 2's trainers get themed decks too.

**Unlocking runs and packs** (agreed): the gym runs are open from the start. The Kanto Gym Challenge needs all 8 Kanto badges (key items, kept by the account), and Kanto Champion a beaten Kanto Gym Challenge (`runTypeLock`; `run.overview` lists each run type with `locked` and how often it's been `beaten`, and `run.start` refuses a locked one). Every run type belongs to a generation (`GENERATIONS` in `run-types.ts`: its region, gyms, Gym Challenge and its sets' packs in release order; Kanto's are Base Set, Jungle, the Wizards promos, Fossil, Base Set 2, Team Rocket, Gym Heroes and Gym Challenge). An account starts with no booster packs: a run's first battle completed without conceding it unlocks the next pack of its generation (`nextPack`), and beating a run unlocks all of them (`apps/api/src/progress.ts`, saved as `PackUnlock` rows when the run is saved; the run log says "Unlocked … booster packs."). Gen 2's runs will unlock packs from Neo Genesis on. The migration `20261024090000_pack_unlocks` gave existing accounts the packs their runs so far would have: all of Kanto's after a beaten run, otherwise one for each run with a battle finished.

The overworld sprites in `apps/web/public/trainers/` are the bosses' front-facing frames from FireRed/LeafGreen (the remake of Red and Blue), taken from the [pret/pokefirered](https://github.com/pret/pokefirered) decompilation (`graphics/object_events/pics/people/`, with their in-game palettes), the background made transparent and trimmed. Beating them gives the Johto badges (Zephyr to Rising) and the Johto Champion Ribbon. **Bosses** (`bosses.ts`) play their counterpart's deck from the Game Boy Color *Pokémon Trading Card Game* (TCG 1), named for the Generation I character: Brock (Gene's Rock Crusher), Misty (Amy's Rain Dancer), Lt. Surge (Isaac's Zapping Selfdestruct), Erika (Nikki's Flower Power), Koga (Rick's Wonders of Science), Sabrina (Murray's Strange Psyshock), Blaine (Ken's Fire Charge), Giovanni (Mitch's First-Strike); the Grand Masters' Legendary decks for the Elite Four, Lorelei (Jack's Articuno, Ice), Lance (Rod's Dragonite, Dragon), and by elimination Bruno (Steve's Zapdos) and Agatha (Courtney's Moltres); and Ronald's Legendary Ronald Deck for Champion Blue. Cards that only exist in the Game Boy game (its promos, its "Mystery" and "Laboratory" prints and the Japanese Fan Book card) are replaced by the closest TCGdex card of the same type, noted on each deck (e.g. Fossil Moltres for the promo Moltres, Fossil Dragonite for the promo Dragonite, Jungle's Eeveelutions, Neo Genesis Super Energy Retrieval). The Japanese-only Pokémon Web Electrode (Lt. Surge, Bruno) is the Base Set Electrode instead. Ronald's promo Articuno and Zapdos are Moltres instead, as no Water or Lightning Pokémon can attack with his Fire and Double Colorless Energy. Bulbapedia's First-Strike and Rain Dancer lists add up to 61, so each has one basic Energy fewer. Bosses play at Gym leader difficulty; a loss costs 1 HP and they're fought again. - **Start**: the first visit sets up the account: a `Starter deck` (`STARTER_DECK`, medium strength, Water/Lightning: Poliwag and Pikachu lines, Lapras, Electabuzz, 17 Trainers, 24 Energy) saved in its deck list with every card in it unlocked, and a first run of **Celadon City** with it. A run starts with 3 HP and ₱500. Older accounts get their starter deck's cards unlocked on their next visit.
- **The map**: the panel beside the map (`RouteChoice`) shows every option of the current step at once, battles together with one deck choice for them, and other encounters together; clicking an option on the map goes there at once, with the current deck. Before a battle you can switch the run's deck for another of your playable decks; it replaces the run's deck (and any trades in it) for the rest of the run (`SET_DECK`, with the deck's name in `RunState.deckName`).
- **Battles**: the trainer plays a random 60-card deck of medium strength (`generateDeck`: 1–2 types, 2–4 middling evolution lines, 14–16 Trainers, all ones a CPU plays (Gym Trainers too: Erika, Misty's Wrath, Master Ball, Brock and Good Manners in any deck; an owner's Trainers and Stadium when the deck has 4 or more of that owner's Pokémon cards, `OWNER_TRAINERS`; Misty's Tears and Fervor in Water and Fire decks), the rest Energy split by the attacks' needs; the same seed gives the same deck) at the CPU's **Trainer** difficulty. Its deck suits the trainer's name: each class (Swimmer, Bug Catcher, Hiker, Bird Keeper…) favours Generation I Pokémon (`trainerFavorites`), whose lines are chosen first and set the deck's types, so a Swimmer plays Tentacruel, Golduck or Starmie rather than any Water Pokémon; other lines join only when the favourites run out. A **Gym Trainer** is the only option on the step before their gym leader: a random deck of the gym's type alone, at Trainer difficulty. **Ace Trainers** (elite battles, from step 6) can be declined; they play at **Gym leader** difficulty and pay more. A win pays ₱ and EXP and offers 1 of 3 cards; a loss costs 1 HP and the run moves on, except against a boss, who is fought again. At 0 HP the run is lost: start over (a new run), or, for testing, **Retry with 3 HP**, which carries on from where it ended (on in production too, for now). Trainer battles on the map lean different ways (`MapEncounter.focus`, rolled with the map: 40% none, 20% each): **Big payout** (twice the ₱), **Extra EXP** (twice the EXP) or **Rarer cards** (reward cards one rarity up), tagged on the map and in the encounter panel (`battleReward`; placeholder amounts, to balance later).
- **Other encounters**: a card shop (cards for ₱ by rarity), a free card (1 of 3), a card trade (one of your deck's cards for one at least as rare; it replaces it in the deck), a Pokémon Center (1 HP for ₱100) and Mystery events: a Frenzy (Pokémon of one type do double damage in the next 3 battles, both sides: the engine's `GameState.rules`), a coin-toss bet, a shady dealer (a rare card for 1 HP), a Fan Club donation (₱ for EXP) and a lucky find.
- **Cards**: a Gen 1 run's cards come from every card the engine plays fully (`cardImplemented`) in the Base Set, Jungle, Fossil, Wizards promos, Base Set 2, Team Rocket, Gym Heroes and Gym Challenge, a Gen 2 run's from every card of Gen 2's sets (see Generations above; `apps/api/src/pool.ts`), rarer ones less often. A card gained in a run is unlocked at once (`CardUnlock`, `apps/api/src/unlocks.ts`) but doesn't join the run's deck (only trades change it): it can go in your next decks on the Collection tab. Unlocks are per card, not per copy (up to the usual 4); basic Energy is always unlocked. A holo with a non-holo version of the same card in its set (same name, HP, attacks, powers and text: Jungle's, Fossil's and Team Rocket's holos, and promo Mew) is a special addition: it counts every copy gained, from packs and runs (`CardUnlock.quantity`), and gaining it unlocks the non-holo version too (`holoTwins` in `unlocks.ts`; the migration `20261021100000_holo_twins` did this for holos already unlocked). Holo-only cards (Base Set's and Base Set 2's holos, most promo holos) are ordinary unlocks with the usual 4 copies. Holo Energy counts copies too. A deck holds no more copies of a special holo or a holo Energy than were gained (`lockedProblem`; the deck builder's `cantAdd` too, from the catalog's `limitedCopies`), so the rest of a playset is the non-holo version. Special holos unlocked before counting began have 1 copy, or the number gained in runs if more (migration `20261021090000_holo_copies`; packs never recorded duplicates), and saved decks holding more were changed to the non-holo version for the extras (`20261022090000_holo_deck_limit`). The starter deck uses Fossil's non-holo Lapras, so the holo one is only gained by pulling it. Base Set 2 reprints earlier cards with the same art, so a Base Set 2 card and the earlier print it matches unlock together, either way round, whenever neither is holo: its commons, uncommons and non-holo rares (104 pairs; Base Set 2's non-holo Kangaskhan, Mr. Mime, Pinsir, Snorlax, Venomoth and Victreebel pair with Jungle's non-holo prints). Holo rares look different (Base Set 2's have the galaxy foil), so they're unlocked separately. Only Base Set 2 (`BASE2_PAIRS` and `unlockCards`; the migration `20261019090000_base2_reprint_unlocks`, after the commons-only `20261018090000_base2_common_unlocks` and `20261018100000_base2_common_originals`, did this for unlocks made before). The Collection tab shows locked cards darker (and still, without the holo effect, when viewed large). The deck builder adds them with a warning and the API saves them (so an imported deck keeps them, see [Deck sharing](#deck-sharing)), but a deck holding any (or more copies of a special holo or holo Energy than were gained) can't start a run or a single battle: it's greyed out and tagged Locked wherever decks are picked.
- **The run deck**: while a run is on, the deck list has an automatic deck, **Current run** (`Deck.runId`, `syncRunDeck` in `runs.ts`), kept a copy of the run's deck: made when the run starts, and updated by every trade or switch of decks (runs from before it get one on the next `run.overview`). It's read-only on the Collection tab (tagged Run deck: no renaming, editing or deleting; Copy to edit makes an ordinary copy), can't start a run, and can be used for single battles. When the run is over, `SaveRunDeck` offers to save it under a name filled in with the run's number and type: it becomes one of your decks (`run.saveDeck`). If it isn't saved, the next run takes it over: it's renamed Current run again and copies the new run's deck, which is one of your own decks.
- **After a run**: beating it adds its EXP to the account and gives the gym leader's badge (a key item). Then comes the shop, where items cost EXP (a different selection after each run: 3–4 consumables, 1–2 misc items and 1 piece of gear, rolled from the run's seed so it stays put until the next run ends), and then the next run, with a run type and one of your playable decks to pick. When a run ends, beaten or lost, its leftover ₱ go into the account's bank (`User.bank`) at once; the next run starts with ₱500. (Retry with 3 HP takes them back out of the bank, as far as it still has them.)
- **Conceding**: while choosing the next step, Concede the run (`ConcedeRun`, the `CONCEDE` run action) ends it as lost (`RunState.conceded`) after asking. The cards gained stay unlocked (they were unlocked as they were gained). Its ₱ are banked only if at least one battle was completed without conceding it, won or lost (`battlesCompleted`, `bankablePokedollars`: the API checks the game's action rows for the player's `CONCEDE` and passes `conceded` with `BATTLE_OVER`; older runs count every battle finished, from the log if need be), so a fresh run's ₱500 can't be banked by conceding its first battle and then the run. The same rule holds however the run ends: a run lost by conceding every battle banks nothing either. There's no EXP (that's for beating a run) and no retry.
- **Items** (`items.ts`; prices and strengths are first guesses, to balance later). Owned items are `InventoryItem` rows.
  - **Equipment** goes in head, chest, legs, Poké Ball and 2 accessory slots (`Equipment`). It's read when each run action is applied, so a change works from the next encounter. Head: ₱ per win, more EXP, more reward cards. Chest: less damage to your Pokémon (of one type, or all). Legs: cheaper Pokémon Centers or Card Shops, more Free Card choices. Poké Balls: more cards in the opening hand, and more cards to pick from. Accessories: +10 damage for one type's attacks (Charcoal, Mystic Water…), more ₱ or EXP, a lucky first coin flip (Coin Case).
  - **Consumables** are used from the Bag before a battle (at most 3 per run) and last a number of battles: X Attack and Dire Hit (more damage), X Defend (less damage taken), X Accuracy (first flips heads), Guard Spec., Antidote, Awakening, Paralyze Heal, Burn Heal and Full Heal (no Special Conditions from attacks), Lemonade (bigger opening hand), Lucky Egg (double EXP), Big Pearl (more ₱).
  - **Misc items** do one thing when used, with their own limits: Escape Rope (leave a battle without losing HP; its game is conceded, and a boss or Gym Trainer stays to be fought again), Itemfinder (reveal the step's Mystery encounters), Repel (re-roll the step's encounters, not at a gym), Potion (heal 1 HP), Nugget (₱300).
  - **In battles**, equipment and consumable effects become the player's battle rules (`damageBonus`, `damageGuard`, `conditionGuard`, `openingHand`, `luckyFlips`; see `BattleRule`), each named for its item. Damage bonuses add to the base damage (after a Frenzy's multiplier, before Weakness); guards come off after Weakness and Resistance, like Defender. In the run, they change battle prizes and EXP, prices, and how many cards are offered.
  - **Key items** are records that can't be removed.
- **API** (`routers/run.ts`, `runs.ts`, `pool.ts`, `unlocks.ts`, `progress.ts`: pack unlocks and run type locks): `run.overview` (with each deck's problems), `act` (with `expectedVersion`, like games), `choose` (an option on the map; for a battle, with `deckId` it switches decks first: `SET_DECK`), `useItem`, `retry`, `start` (a playable deck of your own, not the run deck), `saveDeck` (the run deck, once the run is over), `shop`, `buyItem`, `inventory`, `equip`; `decks.unlocked`. Starting a battle creates a `Game` linked to the run (`Game.runId`); when the game ends, `game.act` (or the next `run.overview`) records the result in the run.

## Booster packs

The ₱ in the bank (each run's leftover ₱, moved there when the run ends) buys booster packs on the **Packs** tab, ₱300 each (`PACK_PRICE`). There's one per set of a generation (`PACK_SETS`: Base Set, Jungle, Fossil, Wizards Black Star Promos, Base Set 2, Team Rocket, Gym Heroes, Gym Challenge, and Gen 2's sets, whose cards' effects are still to come), all shown at first, with a generation filter (`GenerationFilter`) to show only some generations' sets; each bought only once unlocked by runs (see [Runs](#runs): `packs.list` says which are `locked`, and which is `next`; `open` refuses a locked one, the debug `debugOpen` doesn't). Locked packs are dimmed on the page and can't be picked, and their cards can't be crafted with Stardust (`packs.craft` refuses them; the deck builder's Craft button says to unlock the set's packs, from `packs.unlockedSets`). A pack is 11 cards with the usual WOTC-era make-up, averaged rather than each set's own odds: 1 rare, a holo about 1 pack in 3 (`HOLO_CHANCE`), 3 uncommons and 6 commons, all different, and each of those 9 has a chance of being a rare (or holo) instead: 4% while the pack has no extra rare, then 2%, 0.5% and 0.1% (`EXTRA_RARE_CHANCES`; about 31% of packs get an extra rare, 2.5% two or more; a promo pack's extras are holo promos; placeholder odds). Southern Islands, whose 18 cards are all galaxy foil (counted as holos), gives 6 different ones a pack (`HOLO_SET_PACK`, a placeholder). And 0.6% of packs are all rares and holos but their Energy (`ALL_RARES_CHANCE`): the pack window sets off fireworks over the screen for a few seconds (`Fireworks.tsx`, with `canvas-confetti`) and says "All rares!". Each pack has 1 basic Energy of any type: the set's own, or the closest earlier set's by release date (Jungle, Fossil and the promos get Base Set's; Team Rocket gets Base Set 2's), and 2% of the time a holo Energy instead (see [Holo Energy](#holo-energy)). TCGdex lists every promo as Common (10 of them are holo: the 6 TCGdex marks, Venusaur and Cool Porygon, and the galaxy-foil Entei and Pichu, which `cardRarity` counts as holo), so a promo pack's uncommon and rare slots hold more non-holo promos, and its last card is a holo promo about 1 pack in 3; the pack window labels them "Promo" and "Holo Promo". `openPack` in `packages/campaign/src/packs.ts` rolls it; the API's `packs` router (`apps/api/src/routers/packs.ts`: `list`, `open`) takes the ₱ from the bank, rolls the packs on the server and unlocks every card in them, in one transaction, and returns the cards in reveal order (each pack's Energy first and rare last, pack after pack, each with its `pack` number) with which are new unlocks (only the first time a card comes up). Up to `MAX_PACKS_AT_ONCE` (50) packs can be bought at once (`count`). The page shows the sets as packs, each with how many of the cards its packs can hold you've unlocked (`unlockedCount` of `packCards` from `packs.list`, basic Energy aside) and a progress bar; clicking one opens a window (closed with ×, or before opening by a click anywhere but the pack and its controls) with that pack and a quantity picker (×1, ×2, ×5, ×10, or Custom with a Max button for what the bank pays for), and two options remembered in the browser: separate commons and rares (the commons, uncommons and Energy of all the packs are laid out face up together, and the rares stay face down to be opened one by one) and auto open (each card moves on by itself, pausing longer on rares and holos; while it runs, ×2 speed doubles it, and Stop auto goes back to clicking for the rest of the packs, with Resume auto to start it again). Clicking the pack opens them with an animation, then the cards one at a time or all at once (Skip), and finally the list of cards opened. With the commons separated, or several packs on auto open, only the rares are revealed one by one, on the same screen as every card would be, then the list shows every card with the rares (and holos) framed and tagged (a holo Energy too). Any holo or galaxy foil counts as a rare there, whatever slot it came from.

## Favorites

Any card can be marked as a favorite: open it large (right-click it, or on a phone hold it and let go) and press its ★ (`CardInspector`'s `favorite`; `CardInspectProvider` everywhere, the deck builder's own inspector on the Collection tab). Favorites belong to the account (`FavoriteCard` rows; `decks.favorites` lists them, the latest first, and `decks.setFavorite` adds or removes one). On the Collection tab, the search's Favorites toggle (before Pokémon) shows only favorites (`DeckFilter.favorites`). Migration `20261026090000_favorite_cards` adds the table.

## Stardust

Stardust is the account's crafting currency (`User.stardust`). Every card pulled from a pack that you already had gives some (a new unlock gives none), by rarity (`STARDUST_PER_CARD` in `packages/campaign/src/packs.ts`): 50 a common, 100 an uncommon, 300 a rare or holo (a holo Energy too), none for basic Energy. The Packs tab shows how much you have, and the list of cards opened how much the packs gave. It's spent crafting cards on the Collection tab: right-click a card and Craft it (`CardInspector`'s `craft`; `packs.craft`), for 100 Stardust a common or uncommon and 500 a rare or holo (`CRAFT_COST`). Crafting unlocks the card the same way pulling it would (`unlockCards`): once, or for a special holo another copy and its non-holo version. Only cards packs hold can be crafted (the catalog's `craftCost`; not basic or holo Energy), and not one already unlocked unless it counts copies.

## Holo Energy

Holo versions of basic Energy, found only in booster packs: a pack's Energy card is a holo Energy 2% of the time (`HOLO_ENERGY_CHANCE` in `packages/campaign/src/packs.ts`), of the pack's Energy (its set's own, or the closest earlier set's). Each comes in one of every style of the holo card library (`apps/web/src/styles/holo/cards`, all but the single-card `swsh-pikachu.css`: regular and reverse holo, galaxy, amazing and radiant rares, V, VMAX, VSTAR, full arts, rainbow, secret, shiny and the Trainer Gallery styles), picked at random, and each type and style is a card of its own in the catalog: `<energy id>-holo-<style>`, e.g. `base1-98-holo-rainbow`. The seed makes them (`packages/db/prisma/holo-energy.ts`: `HOLO_ENERGY_STYLES` and `HOLO_ENERGY_SETS`, the sets packs take their Energy from), with the style in the card's data (`holoEnergy`), shown by `holoAttributes` and `HoloCard` (its `data-rarity`, `data-trainer-gallery` and any `supertype`/`subtypes` the style selects on).

They're never counted in the number of cards collected: the Packs tab's unlocked count for each set (`packs.list`'s `unlockedCount` of `packCards`, which leave out Energy, basic too) and the Collection tab's count of cards shown leave them out. A deck's card count includes them, as they're cards in it.

They play as basic Energy of their type (no limit by name), but unlike basic Energy they're locked until pulled, and every pull adds one copy (`CardUnlock.quantity`, counted by `unlockCards` like every holo card): a deck holds no more of each than were pulled (`lockedProblem`; the deck builder's `cantAdd` and `decks.save` check it too). The deck builder only lists the ones you've pulled, each as its own card tagged with its style and how many you have ("Holo · Rainbow ×2"). In the pack opener a holo Energy is treated like a rare: revealed in the rares-only stack and glowing like a holo.

## Single battles

The **Practice** tab (`pages/SingleBattle.tsx`) plays one battle outside runs: nothing is won or lost. Pick:
- **Your deck:** one of your decks that can be played (the others are listed with why not), or the fixed Base Set test deck (`PLAYER_TEST_DECK` in `apps/api/src/test-decks.ts`). The deck for the next battle is shown large at the top, with its headline Pokémon and card split, and links to the Collection tab to edit it (`/decks?deck=<id>`) or build a new one (`/decks?deck=new`).
- **Opponent:** a random trainer from the run's map (`TRAINERS`), with a new random deck suiting their name each battle (`generateDeck` with `trainerFavorites`, as in runs), or a boss (any gym leader, the Elite Four or Champion Blue) with their own deck.
- **Difficulty:** Passive, Trainer (the default) or Gym leader, whatever the opponent.

The choices are remembered in the browser (`poke-tcg.single-battle`), so after a battle the Next battle button goes back to the tab with them still picked. `game.create` (`singleBattleInput` in `@poke-tcg/shared`) starts it; the opponent's name is kept in the game's state (`opponentName`) for the banner at the top of the game.

## How a move works

1. Client sends `game.act({ gameId, expectedVersion, action })`.
2. API validates the input with Zod, loads the game state, and runs `applyAction` from `@poke-tcg/game-engine`.
3. If the move is legal, the API runs the CPU (`runCpu`) until it's the player's move again.
4. If `expectedVersion` still matches, the API writes the new state and every action (player and CPU) to the `GameAction` log in one transaction.
5. The response is `frames`: the player's `getPlayerView` after their move and after each of the CPU's, with who moved and the action type. Raw state, which includes the CPU's hand, deck order and RNG, never leaves the server.
6. The web caches the last frame and plays the others back (`pages/Game.tsx`): each move's coin flips play first (1.9s each) while the board still shows the move before, so no result shows before its coin lands; then the move stays up for 0.9s. A click skips a move's flips, and with "Always skip coin flips" (saved per browser) they don't play at all. Nothing can be clicked until the reply ends, coin flips included. Slots animate what changed (`Slot.tsx`): a Pokémon dropping in, a red shake for damage, green for healing, yellow for Energy, and the attacker lunging at the defender.

## The CPU opponent

Each difficulty has its own file in `packages/game-engine/src/cpu/`, with shared helpers in `shared.ts`. A game's `cpuDifficulty` picks one (missing = Gym leader), and the Debug tab can change it mid-game:

- **Passive** (`passive.ts`): benches Basics, evolves and attaches Energy to a Pokémon of the same type. It never attacks, retreats or plays Trainers.
- **Trainer** (`trainer.ts`), for the fights that aren't gym leaders: plays Bill and Professor Oak (same rules as the gym leader), benches and evolves, aims its Energy attachment like the gym leader, heals only its active (Potion at 20+, Super Potion at 40+ if it can still use its best attack), retreats or switches only when the active can't attack this turn or next and a benched Pokémon can, and attacks for the most damage even when that costs Energy or hurts itself. It never uses Pokémon Powers, searches its deck, disrupts, boosts, or looks at the player's next turn. After a Knock Out it promotes the Pokémon with the most HP left.
- **Gym leader** (`gym-leader.ts`): the strongest, described below.

The gym leader takes, on its turn, it takes the first move any of these steps wants, over and over, until it attacks or ends its turn:

1. **Draw and search**: Bill (keeping cards to draw). Computer Search for the next stage of a line in play, or a Basic if the Bench is empty, discarding Energy nothing can use, spare Trainers, Trainers it never plays and Pokémon it can't use (never anything else). Pokémon Trader swaps a Pokémon it can't use for one it wants. It only searches when the card could still be in its deck (counting the face-down prizes). Pokédex isn't played.
   Gym Heroes and Gym Challenge: Master Ball, Brock's Training Method and Erika's Maids (trading 2 cards it can't use) for the next stage of a line in play; Good Manners for a Basic when there's room and none in the hand; Erika (with 3 or fewer other cards and a deck over 8) and Misty's Wrath (deck over 10); Blaine's Last Resort; Secret Mission when 2 or more cards are of no use (it discards only those); Misty's Tears and Fervor when it has Water or Fire Pokémon and no Energy of that type in hand; Rocket's Secret Experiment when it wants a card from the deck.
2. **Develop**: bench Basics, Pokémon Breeder straight to Stage 2, Giovanni when it lets a Pokémon with Giovanni in its name evolve now, evolve (active first), Max Revive paid with 2 Energy cards nothing can use, and a Clefairy Doll only when the Bench is empty.
3. **Energy**: Rain Dance and the turn's attachment go to the active if they make a new attack usable, otherwise to the benched Pokémon they bring closest to attacking; Double Colorless only where two colorless symbols are open, and never Energy no attack can use. Energy Trans moves Grass Energy from the Bench to the active when that makes a stronger attack usable. Then Professor Oak, if the hand is down to 2 other cards (and the deck has more than 7). Blaine, when a Pokémon with Blaine in its name is 2 or more Energy from its strongest attack and the hand has 2 Fire Energy cards: both go to it.
4. **Heal**: Full Heal for a Special Condition; Super Potion on the active at 40+ damage if it can spare the Energy and still use its best attack, else the most damaged benched Pokémon at 40+; Potion at 20+ damage (active first); Pokémon Center for 60+ healed when the active isn't about to attack with Energy it would lose; Damage Swap moves damage counters off an active that would be Knocked Out. Gym sets: Celadon City Gym for a Special Condition on its Active Pokémon with Erika in its name, if it can spare an Energy card; Brock once 2 or more of its Pokémon are damaged; Erika's Kindness when it heals 30 or more of its own and more than the player's; Giovanni's Last Resort on a Pokémon with Giovanni in its name at half its HP or worse, with 2 or fewer other cards in hand.
5. **Disrupt**: Energy Removal on the player's active (else the Pokémon closest to its strongest attack); Super Energy Removal only when both Energy were going towards one attack, discarding its own Energy that's missed least; Gust of Wind for a Knock Out, else to strand a benched Pokémon with no Energy and a Retreat Cost of 2+. The Rocket's Trap against 3 or more cards in the player's hand; an owner's Stadium (Pewter, Cerulean, Celadon, Viridian, Vermilion or Cinnabar City Gym) when it has 2 or more of that owner's Pokémon in play and more than the player (`OWNER_STADIUMS`); Brock's Protection on its Pokémon with Brock in its name that has the most Energy (2 or more).
6. **Retreat or Switch** (Switch first): when the active can't attack this turn or next but a benched Pokémon can; when it would be Knocked Out next turn (and isn't Knocking Out the attacker first) and a benched Pokémon would survive; or when it still has a Special Condition. The benched Pokémon that attacks best comes in. The Retreat Cost is paid with the Energy it can best spare, basic before special, and never when nothing could attack afterwards.
7. **Boost**: any Pokémon Power that makes this turn's attack better without costing a Pokémon or prize (Energy Burn); PlusPower when +10 makes a Knock Out, then Misty (discarding 2 cards it can't use); Koga before a Pokémon with Koga in its name damages one that isn't Poisoned; Defender when −20 stops a Knock Out next turn, and Koga's Ninja Trick on an Active Pokémon with Koga in its name that would be Knocked Out.
8. **Tickling Machine**, only when it has no attack that does damage (tails would end its turn).
9. **Attack**: the cheapest attack that Knocks Out, otherwise the most damage. Attacks that hurt the attacker or discard its Energy only when they Knock Out or nothing else does damage.

After a Knock Out it promotes the benched Pokémon that attacks best (then the one with the most HP left). It plays no other Trainers yet (Lass, Impostor Professor Oak, Item Finder, Maintenance, Revive, Pokémon Flute, Scoop Up, Devolution Spray, Energy Retrieval, and the promos' Computer Error, Lucky Stadium and Pokémon Tower), never uses Buzzap, Lucky Stadium or the promo powers it doesn't recognise, and only answers the choices other cards ask of it: every difficulty draws 5 for Computer Error, takes an Eevee evolution for Chain Reaction, puts back the card it wants least for Special Delivery, and keeps the Energy that leaves Suicune closest to attacking for Pure Body.

It only uses what the player could see. What an attack would do is worked out in `cpu/shared.ts` by playing it on copies of the state with fixed coin flips covering every heads/tails pattern of three flips, so it never knows the real flips to come; "Knocks Out" means in at least half of those outcomes. The player's threat is their active's best attack next turn with the Energy it has now. Trainers and powers are recognised by name, so reprints work the same, and nothing depends on the current test decks.

## Deck builder

The **Collection** tab (`pages/Decks.tsx`) builds decks for runs and single battles. It opens on the deck list: a button per deck showing its name, card count, its 3 headline Pokémon and how its cards split between Pokémon, Trainers and Energy. The headline Pokémon are the highest stages, preferring an evolved Pokémon with 2 or more copies of each earlier stage in the deck, then the most copies, one per evolution line while there are enough lines. From the list you can start a new deck, rename one with the pencil button by its name (Enter or clicking away saves the name, Escape cancels), copy one (the copy, "<name> (copy)", goes at the end and opens for editing), or drag decks into a new order (`Deck.position`, which Play's deck pickers follow too). Click a deck to open it: it stays at the top as a button back to the list, where its pencil button renames it (saved with the deck's Save, like its cards), with Save and Delete and its cards below, where − and + change the counts; click cards in the search to add copies. Right-click any card (in the search, the open deck, or a deck's headline Pokémon) to see it large, as holding it does; it stays open until Escape or a click outside, and with a deck open it has − and + to change the card's copies in it. Decks are saved per user (`Deck`, `DeckCard`) through the `decks` router (`apps/api/src/routers/decks.ts`: `list`, `get`, `save`, `rename`, `duplicate`, `reorder`, `delete`, and `exportCode`/`importCode` for [Deck sharing](#deck-sharing)).

The rules (`packages/shared/src/deck.ts`, used by both the builder and the API) are the rulebook's: exactly 60 cards; at most 4 cards with exactly the same name, across all sets, except basic Energy (TCGdex "Normal" Energy; Double Colorless, Darkness and Metal Energy are special); at most 4 Basic Pokémon with Unown in their names, whatever their letters (printed on every Unown: `MAX_UNOWN`, `unownCount`; the random decks take one Unown at most); at most 1 of each Shining Pokémon and 1 Miracle Energy (printed on them: `onlyOnePerDeck`, `maxCopiesOf`; the random decks take no Shining Pokémon); and at least one Basic Pokémon (Baby Pokémon count; Clefairy Doll and Mysterious Fossil don't). An unfinished deck can be saved, but never one over 60 cards, with more than 4 of a name or with more than 4 Unown, and only a deck with no problems can start a run (`run.start`) or a single battle (`game.create`).

Only a deck of unlocked cards can be played (see [Runs](#runs)): the starter deck's cards, every card gained in a run, and basic Energy, which always is. Locked cards are darker on the Collection tab, and shown still, without the holo effect, when held or right-clicked. They can still go in a deck (agreed with the user, for imported decks): adding one shows a warning, the deck lists "Holds cards you haven't unlocked" as a problem (`hasLockedCards`, `LOCKED_DECK_PROBLEM`; the API's `decks.list` and `run.overview` say `locked`), and it's greyed out, tagged Locked, wherever a deck is picked. The API saves such a deck (`checkCards` in `routers/decks.ts` checks only the size, 4-of-a-name and Unown rules), but won't start a run or battle with it (`playableDeck`).

Every catalog card can go in a deck. `cards.list` marks the ones the engine fully implements (`isImplemented` in `apps/api/src/cards.ts`: every attack with text, its power, its Trainer effect, or basic, Double Colorless, Rainbow, Full Heal and Potion Energy), for the Works and Not work filters and the deck list's "(partial)". The rest still load: their Pokémon attack for base damage, while their other attack effects, powers, Trainer effects (the card can't be played) and special Energy effects (1 Energy of its type, or Colorless) do nothing yet.

The kind toggles (Pokémon, Trainer, Energy) show any of the kinds that are on; with none on, every kind shows, so Trainer and Energy together show every Trainer and Energy card. The type toggles pick types for Pokémon (their type) and Energy (the type it provides; special Energy without one of its own, like Double Colorless, is Colorless) alike. The type toggles and the Pokémon filters (stage, HP, has ability) only say something about the cards they apply to: the cards they don't apply to (Trainers for the types; Trainers and Energy for the Pokémon filters) still show when their kind is on, and are hidden otherwise. So Fire alone shows Fire Pokémon and Fire Energy, and Fire with Pokémon and Trainer on shows Fire Pokémon and every Trainer (`filterForDeck`).

## Deck sharing

Decks can be shared as codes and published for everyone (agreed with the user):

- **Share codes** (`apps/api/src/deck-codes.ts`): a deck's name and cards, deflated and base64url-encoded behind `PTCG1.` (a 60-card deck's is about 230 characters). The open deck's Share button (a saved deck, its changes saved) shows its code to copy (`decks.exportCode`); the deck list's Import button pastes one (`decks.importCode`), which is saved as a new deck at the end of the list and opened. Spaces and line breaks from pasting are ignored.
- **Holos**: a code (and a community deck) lists each card's non-holo version when it has one (`plainCards`: a special holo's twin from `holoTwins`, a holo Energy's basic Energy), so it doesn't say which holos its author pulled. Importing puts back as many of the importer's own holos as they have of each (`withOwnHolos`, the most-pulled holo Energy style first) and fills the rest with the non-holo version.
- **Locked cards**: an import keeps the cards the importer hasn't unlocked (`importDeck` in `routers/decks.ts`); the deck just can't be played until they are (see [Deck builder](#deck-builder)), and the deck builder says so when it opens.
- **Community Decks** (`pages/Community.tsx`, `routers/community.ts`; `CommunityDeck`, `CommunityDeckCard`, migration `20261029090000_community_decks`): the Share dialog's Publish puts a snapshot of the deck on the Community Decks tab with an optional description (`community.publish`; only a deck that follows the rules, locked cards or not). Later changes to the deck don't change it; publishing again adds another. Every account sees the latest 200 (`community.list`) with the author's account name (never their Google name or email; see below), and can import one (`community.import`, as with a code) or copy its code. Authors can unpublish their own (`community.unpublish`).
- **Account name** (`User.accountName`, migration `20261030090000_account_names`): the name a player shares decks under, chosen from the header's account menu, the Community Decks tab or the Share dialog (`AccountNameField`; `community.accountName`, `community.setAccountName`): 2–20 letters, numbers, spaces and `. _ ' -`, not unique (anyone may use any name). Publishing needs one. Changing it changes the name on the account's published decks. The Google profile's name (`User.displayName`, copied at each sign-in) is never shown to other players.

## Debug tools

The game log has a **Debug** tab for testing: change the CPU's difficulty, draw a card, put any card (or an Energy) into your hand, set the HP of any Pokémon in play, and turn Special Conditions (Asleep, Confused, Paralyzed, Poisoned, Burned) on or off on either active, for example to try Burned before any card inflicts it. It only exists outside production, enforced in two places:

- **API** (the authority): the `debug.run` procedure is a `debugProcedure` (`apps/api/src/trpc.ts`), which answers `NOT_FOUND` unless `env.debugEnabled` (`apps/api/src/env.ts`). That's always false in production (`VERCEL_ENV=production` or `NODE_ENV=production`, whatever else is set), and true elsewhere unless `ENABLE_DEBUG=false`. `debug.enabled` tells the client which.
- **Web**: `__DEBUG_BUILD__` is a build-time constant from `vite.config.ts`: on in the dev server (unless `VITE_ENABLE_DEBUG=false`), off in a `vite build` (unless `VITE_ENABLE_DEBUG=true`). A production build leaves the Debug tab's code out of the bundle entirely; the tab also needs `debug.enabled` from the API.

The pack window has two more, **Debug: force holo Energy** and **Debug: force all-rares pack**: every pack opened gets a holo Energy, or is all rares (for the fireworks), for testing them (`packs.debugOpen`, a `debugProcedure`; the checkbox is behind `__DEBUG_BUILD__` and the API's debug switch like the Debug tab).

In debug mode the run picker also unlocks every run type, the Gym Challenges and Champion runs included (started with `run.debugStart`, a `debugProcedure`; the picker's override is behind `__DEBUG_BUILD__` and the API's debug switch).

During a run, each battle in the next-encounter panel has a **Skip battle** button under its Battle (or Challenge) button: it chooses the battle (with the deck picked, an Ace Trainer's accepted) and wins it at once without opening the game, so the run goes on to its rewards (`run.debugSkipBattle`, a `debugProcedure`: the battle's game is ended with the engine's `WIN` debug command, saved as a `DEBUG` action row, then settled like any won battle; the button is behind `__DEBUG_BUILD__` and the API's debug switch).

Debug commands go through the engine's `applyDebug` (`packages/game-engine/src/debug.ts`), are written to the game log as "Debug: …", and are saved in the `GameAction` log as `{ type: 'DEBUG', command }`.

## Setup

Requires Node 24+, pnpm, and Docker if you want local Supabase.

```sh
pnpm install
cp .env.example .env        # fill in values (see below)
pnpm db:migrate             # create tables (prompts for a migration name)
pnpm db:seed                # load the WOTC card catalog (1999–2003) from the TCGdex snapshot, plus the hand-made cards
                            # (TCGdex's mistakes are corrected on the way in: TCGDEX_FIXES in prisma/seed.ts, e.g. promo Jigglypuff's 50 HP)
pnpm dev                    # web on :5173 and API on :8787, both with live reload
```

### Option A – hosted Supabase project

1. Copy the pooled (6543) and direct (5432) connection strings into `DATABASE_URL` and `DIRECT_URL`. They're under **Project Settings → Database**.
2. Copy the project URL and anon key into `SUPABASE_URL`, `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
3. Enable the Google provider under **Authentication → Providers**.
4. Under **Authentication → URL Configuration**, add `http://localhost:5173` and your Vercel URL to the redirect URLs.

### Option B – local Supabase (Docker)

```sh
pnpm supabase:start         # prints the local URLs and keys
```

Use the printed DB URL for both `DATABASE_URL` and `DIRECT_URL`, `http://127.0.0.1:54321` as the Supabase URL, and the printed anon key. If the local project signs tokens with HS256, also set `SUPABASE_JWT_SECRET`.

### Google OAuth

1. In Google Cloud Console, create an OAuth client ID of type *Web application*.
2. Add this authorized redirect URI: `https://<project-ref>.supabase.co/auth/v1/callback`. For local Supabase use `http://127.0.0.1:54321/auth/v1/callback`.
3. Paste the client ID and secret into the Supabase dashboard. For local Supabase, set `SUPABASE_AUTH_EXTERNAL_GOOGLE_CLIENT_ID` and `SUPABASE_AUTH_EXTERNAL_GOOGLE_SECRET` in `.env`.

## Deploying to Vercel

1. Import the repo into Vercel and leave the **Root Directory** as the repo root. `vercel.json` sets the build command, which writes `.vercel/output` (Build Output API): the web app as static files and the API bundled into one function serving `/api/*`.
2. Add the variables from `.env.example` in the Vercel project settings. Use the **pooled** `DATABASE_URL`.
3. Run migrations against production from your machine or CI with `pnpm --filter @poke-tcg/db migrate:deploy`. They don't run during the Vercel build, so preview deploys can't touch the production schema.
