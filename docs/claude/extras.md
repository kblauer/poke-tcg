# Extras and Who's That Pokémon?

Moved out of CLAUDE.md word for word (2026-10-26) so it loads only when needed. Everything here is still agreed with the user and binding.

- Extras (asked for 2026-10-24, beside the roadmap): the Extras tab (`/extras`, Xtransceiver icon) lists minigames and modes, starting with the Berry Farm and the Berry Blender (README: Extras). Their assets come from pokeemerald via `tools/extras/emerald_extras.py` (generated files: `berry-data.ts`, `berry-farm-map.ts`, `public/extras/`). The blender is a frame-by-frame port of `berry_blender.c` (keep it faithful, its bugs included); the farm's `GROW_HOURS` (4) is a placeholder ("TBD"). Pokéblocks have no use yet. The Game Corner (`/extras/game-corner`) ports `roulette.c` and `slot_machine.c` the same way (`tools/extras/emerald_roulette.py`, `emerald_slots.py`); coins (`User.coins`) are bought with banked ₱ at the game's prices and have no prize corner yet; the API settles each round (`extras.coinRound`, `coinRoundError`). Poffin cooking (asked for 2026-10-24) is a frame-by-frame port of pokeplatinum's `ov83_0223F7F4.c`/`poffin.c` (`poffin-cooking.ts`, single-player), its assets and sounds by `tools/extras/platinum_extras.py` (and `nds_render.py`); it uses Platinum's berry values (`berry-data-gen4.ts`), not Emerald's. Poffins have no use yet. Voltorb Flip (`/extras/voltorb-flip`, asked for 2026-10-24) is a frame-by-frame port of pokeheartgold's `src/voltorb_flip/` (`voltorb-flip.ts`, `VoltorbFlipScreen.tsx`), its assets, text and sounds by `tools/extras/hgss_voltorb_flip.py` (HGSS's sound archive read by `sdat.py`); its coins go into the same `User.coins` (9999 cap, not HGSS's 50,000), the API makes each board and settles each round against it (`extras.voltorbRound`, `voltorbSettle`, `User.voltorbFlip`). The minigames share one sound volume (`MinigameSound`, `MinigameVolume`).
- Who's That Pokémon? (asked for 2026-10-26, on the `whos-that-pokemon` branch; README: Who's That Pokémon?): a holo's Pokémon as the anime's silhouette, named by typing. A run Mystery event (`whosThat`: 10 s for EXP, a random holo or the rotating list's of the day) and an Extras mode (`/extras/whos-that`: 10 in a row, timed by the server, fastest and average recorded; a daily playlist, one go a day; public leaderboards). Never draw silhouettes ahead of time (the user's): the API reads the holo mask and sends only the shape (`apps/api/src/whos-that.ts`), the browser paints it (`utils/whosThat.ts`, as `tools/whos-that/whos_that.py` draws it). The browser must never get a round's card id or mask file before it's answered (`runView` hides the event's `cardId`); answers and times are checked on the server only.
